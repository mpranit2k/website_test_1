# Video Module

Triggers: video files, Vimeo, YouTube, Mux, CDN-hosted video, background video, scroll-linked video, embedded provider players, video masks, video posters, video-driven motion graphics.

Never silently substitute a static image for a video-driven source asset (core Fidelity Gap Rule and Approval Gate apply).

## Discovery additions

- Identify the exact video source and type: original asset, external embed, streamed provider asset, local file, generated, or protected. Record the source URL when available.
- Document: playback, autoplay, mute state, controls, loop, poster image, aspect ratio, crop and object-fit, masking, opacity, transforms, scroll coupling, loading behavior, provider restrictions, responsive behavior.

## Implementation

Classify each video using the core Asset Classification and record it — with the reason alternatives were rejected — in the Asset Preservation Table. Include video-driven motion in the Animation Audit.

## Validation additions

Verify video is present, moving, correctly positioned, correctly masked and cropped, responsive, and behaviorally aligned with the source. If the original cannot be embedded, preserved, or recreated: flag a Fidelity Gap and request approval before approximation.
