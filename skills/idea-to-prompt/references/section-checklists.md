# Section Checklists

For each section type, the fields to consider filling (either from user input or a stated default/assumption).

## Hero
- Background: color / gradient / image / video (autoplay, muted, loop, playsInline if video)
- Nav bar (if part of hero): brand name, desktop links, mobile hamburger behavior
- Headline (1-2 lines, exact copy or placeholder)
- Subheadline
- Primary + secondary CTA buttons (label, style, hover state)
- Overlay/scrim treatment if background is media
- Vertical alignment / centering approach
- Height (100vh vs fixed vs content-based)

## Features / Benefits
- Section heading + optional subheading
- Number of feature items (3, 4, 6 are common)
- Per-item: icon/image, title, short description
- Grid vs. alternating layout
- Responsive column collapse behavior

## Pricing
- Number of tiers
- Per-tier: name, price, billing period toggle (monthly/annual) if any, feature list, CTA button
- "Most popular" / highlighted tier treatment (border, scale, badge)
- Responsive: grid on desktop, stacked on mobile

## Testimonials / Social Proof
- Layout: carousel, grid, single quote
- Per-item: quote text, author name, role/company, avatar
- Logos strip (if applicable): list of brand names/placeholders

## FAQ
- Number of Q&A items
- Accordion vs. static list
- Expand/collapse interaction and icon

## CTA / Booking banner
- Heading + supporting line
- Single primary button (label, destination/action)
- Background treatment

## Footer
- Columns (links grouped by category)
- Brand/logo
- Social icons
- Legal/copyright line
- Newsletter signup (if applicable)

## About / Story
- Heading
- Body copy block(s)
- Supporting image or stat callouts

## Stats / Numbers
- Number of stats (3-4 common)
- Per-stat: number/metric, label, optional icon
- Animation on scroll (count-up) if implied

## Gallery / Showcase
- Grid vs. carousel
- Image count and aspect ratio
- Lightbox/expand behavior if any

## Contact / Form
- Fields (name, email, message, etc.)
- Validation behavior
- Submit button state (loading/success/error)
- Layout: form only vs. form + info panel
